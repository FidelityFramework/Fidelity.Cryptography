# Candidate selection

[Selection.clef](Selection.clef) exercises the pure candidate-selection scaffold with synthetic records. It selects a matching protected-key domain, refuses software fallback for that key, and refuses a decrypting device when private staging is too small.

The records describe no real board and perform no cryptography. They demonstrate the API policy before an accepted provider registry, key handles and operation executor are implemented. See the [roadmap](../../docs/hacl-implementation-roadmap.md) for the required binding and proof work.
